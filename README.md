# Portfolio Project

This project showcases a responsive portfolio website with a Bento Box UI, custom styles, and interactive elements.

## File Structure

### Pages

- **Index.html**
  Main landing page for the portfolio. Features navigation, hero section, gradient color pickers, and a Bento Box UI for project highlights.
  [Index.html](Index.html)

- **bento.html**
  Demonstrates a standalone responsive Bento Box UI with interactive magnetic effect on boxes.
  [bento.html](bento.html)

- **bhoral.html**
  Project detail page for "Bhoral", including about, gallery, and contact sections.
  [bhoral.html](bhoral.html)

- **bhoral_UI.html**
  Enhanced Bhoral UI case study page with detailed design breakdowns, card components, categorisation views, and mockups.
  [bhoral_UI.html](bhoral_UI.html)

- **SLBRide.html**
  Project detail page for the "SLB Ride" case study.
  [SLBRide.html](SLBRide.html)

### Stylesheets

- **styles.css**
  General styles for layout, typography, navigation, hero, and responsive design.
  [styles.css](styles.css)

- **bentoStyles.css**
  Styles for the Bento Box UI, including grid layout, item sizing, and responsive adjustments.
  [bentoStyles.css](bentoStyles.css)

- **bentoLayout.css**
  Layout-specific styles for the Bento grid structure.
  [bentoLayout.css](bentoLayout.css)

- **buttonStyle.css**
  Styles for call-to-action buttons used in Bento boxes.
  [buttonStyle.css](buttonStyle.css)

- **navbar.css**
  Styles for the navigation bar across pages.
  [navbar.css](navbar.css)

- **casestudy.css**
  Styles for case study pages, including section layouts and typography.
  [casestudy.css](casestudy.css)

- **personalBentoGrid.css**
  Styles for the personal/portfolio-themed Bento grid layout.
  [personalBentoGrid.css](personalBentoGrid.css)

- **schoolBentoGrid.css**
  Styles for the school-themed Bento Box layout.
  [schoolBentoGrid.css](schoolBentoGrid.css)

### Scripts

- **scripts.js**
  JavaScript for magnetic button effects, hamburger menu toggle, Bento box interactions, and gradient color picker functionality.
  [scripts.js](scripts.js)

- **casestudy.js**
  JavaScript specific to case study page interactions.
  [casestudy.js](casestudy.js)

- **interactions.js**
  General interaction utilities and event handlers.
  [interactions.js](interactions.js)

### Assets

- **Bhoral UI/**
  Image assets for the Bhoral UI case study: card details, card types, categorisation views, mockups (mobile & tablet), and the Bhoral logo SVG.

- **SLB_Ride/**
  Assets for the SLB Ride case study, including a photo and the project roll PDF.

- **ProjectThumbnails/**
  Thumbnail images used in the portfolio Bento grid for each project (Bhoral, Participatory Design).

## Features

- **Responsive Bento Box UI**
  Flexible grid layout for showcasing projects with different box sizes.

- **Magnetic Button Effect**
  Interactive hover effect for buttons and Bento items.

- **Customizable Gradient Background**
  Users can pick colors to change the background gradient.

- **Navigation & Hamburger Menu**
  Responsive navigation with hamburger menu for mobile devices.

- **Project Detail Pages**
  Dedicated pages for Bhoral, Bhoral UI, and SLB Ride case studies.

## How to Run

Open [Index.html](Index.html) in your browser to view the portfolio.
Other HTML files can be opened directly for their respective demos.
